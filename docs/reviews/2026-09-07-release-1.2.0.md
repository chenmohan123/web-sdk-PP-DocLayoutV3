# 1.2.0 本地发布验收

日期：2026-09-07。范围：单 SDK、当前模型 Demo、消费者示例和发布文档。验证时分支为 `codex/standard-release-20260907`，基线提交为 `4a1e8e0`，本报告对应其上的待提交修改。本轮未提交、推送、创建标签或发布 npm。

## 版本与发布内容

SDK package、`CURRENT_SDK_VERSION`、API 报告、SDK manifest、版本回归、双语安装文档和 CDN 示例均使用 `1.2.0`。模型版本仍为 `1.0.2`，标准 schema 仍为 `1.1.0`。四种框架示例使用当前本地 SDK，并补齐独立安装和运行说明。

发布说明见 [1.2.0](../releases/1.2.0.md)，列明模型来源、Apache-2.0、默认资产的大小与 SHA-256、WASM/WebGPU、缓存 API、兼容字段和限制。README 中存储类型已更正为 Cache Storage/内存；中文兼容性文档中重复且矛盾的旧后端表已移除。历史模型、benchmark 和审计证据没有重写。

最终源码包括初始化清单取消与旧损坏缓存校验的删除代次保护。SDK 的四项新回归覆盖当前模型/SDK 全清与内存/持久缓存的组合；Demo 覆盖同来源的迟到清单不能覆盖已加载模型身份。

## 环境与干净副本

Windows x64 `10.0.26200`、Node `24.16.0`、pnpm `11.16.0`、Playwright `1.62.1`、Chromium `151.0.7922.34`。

原工作区的历史 `work/pytest-basetemp-20260815` 不可遍历。本次将当前跟踪文件和新增源文件复制到 `work/release-1.2.0-clean`，在副本将文本换行归一到 LF，模拟 Linux CI 检出；安装使用原锁文件和 `pnpm install --frozen-lockfile`。原目录、历史目录权限和 CI 检查门槛均未更改。

首次放在 `node_modules/.cache` 的源码副本会被 API Extractor 当作外部包，因此正式验证副本使用上述 `work` 独立目录。日志与 tarball 仍放在根目录 `node_modules/.cache`，避免浏览器测试清理 `test-results` 时丢失。

Demo 回归在主代理上一轮结束后顺序执行，通过 `DEMO_BASE_URL=http://127.0.0.1:4274` 复用开发服务；源码与最终副本一致。独立消费者和打包浏览器测试使用本次构建的 SDK tarball，不读取旧 npm SDK。
