# SDK v1.1.0 Release Preparation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare a verified `web-sdk-pp-doclayoutv3@1.1.0` release commit for the completed per-class threshold feature without changing model version `1.0.2` or triggering publication.

**Architecture:** Treat the package version and `CURRENT_SDK_VERSION` as the two canonical SDK version sources, then regenerate the API report and synchronize focused contract tests around them. Keep the release mechanical: changelog, metadata, tests, and generated API surface only; the existing tag-driven Trusted Publishing workflow and model assets remain untouched.

**Tech Stack:** pnpm workspace, TypeScript, Vitest, React/Vite, Playwright, Node.js test runner, API Extractor, Prettier, ESLint
